# src/features

Feature modules (e.g. `people`, `participation`, `relationships`,
`nominations`, `institutions`, `projects`, `publications`, `oral-histories`,
`forum`, `search`, `network`, `analytics`, `admin`). Each future feature
should own its own components, server actions/queries, and types, kept
separate from generic UI and from other features. See
docs/architecture.md for the planned module boundaries.

No feature modules exist yet — this project currently only contains the
application foundation.
